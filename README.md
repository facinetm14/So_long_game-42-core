# So Long

A tile-based C game built with MiniLibX. Compare the [minimal map](map_minimal.ber) with the [map validator](srcs/checker_map.c), then follow the [renderer](srcs/display_map.c) and [keyboard handling](srcs/key_mapping.c).

The bundled graphics library includes macOS Objective-C sources. Consult the [Makefile](Makefile) for the platform libraries before building with `make`.
